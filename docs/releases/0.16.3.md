# Forge 0.16.3 release notes

Forge 0.16.3 completes the initial portability series with deterministic Unreal Engine 5.4+ project export. The ZIP contains a normal `.uproject`, Forge source media and Interchange data, plus a two-module C++ plugin: an Editor importer and a gameplay Runtime module.

The Editor importer uses AssetTools, Unreal world/actor/component APIs, Paper2D assets and Enhanced Input assets to reconstruct the supported project subset under `/Game/Generated/Forge`. Stable Forge GUIDs and the full source component JSON remain attached through `UForgeIdentityComponent`. Sprite clips become PaperFlipbooks, scene hierarchies become attached actors, and supported Graph Behaviours use `UForgeGraphComponent` at runtime.

Forge emits no `.uasset` or `.umap` binaries and does not use Unreal Python for gameplay. Unreal creates and owns target binary assets. The source IR, manifest and complete portability report remain outside binary Content assets for review and deterministic reimport.

UI/UMG, Niagara, 2D lighting, prefab authoring assets, exact animation state logic, complete Enhanced Input modifier parity, arbitrary TypeScript, and platform services remain explicitly reported for manual target-side work. Forge remains canonical and no round trip is claimed.
