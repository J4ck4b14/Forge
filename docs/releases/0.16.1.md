# Forge 0.16.1 release notes

Forge 0.16.1 delivers deterministic Godot 4 export from Interchange IR v1. The editor can download a complete project ZIP containing normal Godot project and scene files, copied source media, stable Forge GUID metadata, input and audio-bus configuration, generated core 2D nodes, a portable Behaviour Graph runtime, the source IR, an export manifest and the complete portability report.

The exporter centralizes Forge's pixel/Y-down transform contract, preserves hierarchy and source identity, and keeps generated content isolated under `Generated/Forge`. Unsupported or approximate semantics remain visible in the report. Forge remains canonical; the output is intentionally one-way and does not claim arbitrary TypeScript translation or round-trip editing.
