# Forge 0.16.2 release notes

Forge 0.16.2 delivers deterministic Unity 2022.3+ project export from Interchange IR v1. The generated project uses an Editor importer and public Unity APIs to create scenes, GameObjects, stable Forge identity components, sprite/media references, Rigidbody2D and Collider2D setup, physics layers, cameras, audio sources, particles, Input System actions, AnimationClips, AnimatorControllers and portable Behaviour Graph components.

The bundle includes source media, Forge IR, the stable-ID manifest and the complete portability report. Target coordinates come from the centralized Unity profile. Unity generates its own serialized assets and `.meta` files during import; Forge does not synthesize undocumented scene YAML as its primary export format.

Forge remains canonical and export is one-way. UI, 2D render-pipeline lighting, source prefabs, advanced animation thresholds, arbitrary TypeScript and target platform services remain explicitly classified for manual work or review.
